# 浏览器扩展 · 网申助手 Copilot

半自动校招网申辅助。**不代登录、不破解验证码、不自动提交**——所有"提交"动作由你本人完成；扩展只做：推荐简历、自动填表、上传简历、提交成功后弹"记录投递"气泡。

## 架构

```
仪表板(localhost:8787) ─┐
                        ├─→ 本地后端 server.py(FastAPI, 127.0.0.1:8787)
浏览器扩展(popup/content) ┘        │
   popup(选目标公司/匹配简历)       ├─ copilot.py(multi-resume + JD 匹配)
   content(填表/传简历/记录气泡)    ├─ filler.py(字段映射)
                                   └─ apply.py mark(写入 applications.json)
```

扩展的 background service worker 是 HTTP 客户端，popup / content 都通过它访问后端；后端只在 `127.0.0.1` 监听，不外网开放。

## 1. 启动本地后端

```bash
cd apply-copilot
python server.py            # 默认 http://127.0.0.1:8787
# 自定义端口： python server.py --port 9xxx
```

启动后打开 http://127.0.0.1:8787/ 即为状态化投递队列仪表板。

## 2. 加载扩展（Chrome / Edge，MV3）

1. 浏览器地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录 `apply-copilot/extension/`。
4. 固定扩展图标到工具栏，方便点开 popup。

> 每次修改扩展文件后，回到 `chrome://extensions` 点该扩展的「刷新」即可生效。

## 3. 日常用法

1. **开仪表板**：http://127.0.0.1:8787/ → 看清单状态（未投/进行中/已记录），点「打开」进网申页（自动标记进行中）。
2. **设当前目标**：点扩展图标 → 选「当前目标公司」→「设为当前目标」。
3. **匹配简历**（可选）：popup 里粘 JD →「匹配简历」→ 推荐版本会缓存，供上传简历使用。
4. **在网申页**：
   - 点右下角 🛠 浮标展开工具条；
   - 「① 填充表单」：扫描页面字段并按档案填值（未命中的红框标出，需你手填）；
   - 「② 上传推荐简历」：把推荐简历 PDF 塞进文件上传框；
   - 你本人登录、填开放题、过验证码、**点击提交**。
5. **记录**：扩展检测到"提交成功"页会高亮「③ 记录投递」；点它 → 填岗位标题（公司已预填）→ 确认 → 入库 applications.json，仪表板状态变「已记录」。

## 4. 合规与安全

- 后端仅监听 `127.0.0.1`；CORS 放宽为 `*` 仅为让任意公司页面上的扩展能跨域请求本机后端，**请勿用 `--host 0.0.0.0` 暴露到公网**。
- 扩展不读取任何账号凭据，不写运行日志；PII 只留在本地 `profile.job.json` / `kits/`。
- 绝不自动提交、绝不绕过风控/验证码。
