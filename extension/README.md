# 浏览器扩展 · 网申助手 Copilot

半自动校招网申辅助。**不代登录、不破解验证码、不自动提交**——所有"提交"动作由你本人完成。填表前会展示匹配建议和可勾选字段；点击“填充勾选字段”后才修改网页。

## 架构

```
仪表板(localhost:8787) ─┐
                        ├─→ 本地后端 server.py(FastAPI, 127.0.0.1:8787)
浏览器扩展(popup/content) ┘        │
   popup(选目标公司/匹配简历)       ├─ copilot.py(multi-resume + JD 匹配)
   content(填表/传简历/记录气泡)    ├─ filler.py(字段映射)
                                   └─ apply.py mark(写入 applications.json)
```

扩展的 background service worker 是 HTTP 客户端，popup / content 都通过它访问后端；后端只在 `127.0.0.1` 监听，不外网开放。

## 1. 启动本地后端

```bash
cd apply-copilot
python server.py            # 默认 http://127.0.0.1:8787
# 自定义端口： python server.py --port 9xxx
```

启动后打开 http://127.0.0.1:8787/ 即为状态化投递队列仪表板。

## 2. 加载扩展（Chrome / Edge，MV3）

1. 浏览器地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录 `apply-copilot/extension/`。
4. 固定扩展图标到工具栏，方便点开 popup。

> 每次修改扩展文件后，回到 `chrome://extensions` 点该扩展的「刷新」即可生效。

## 3. 日常用法

1. **填基础档案**：点扩展图标，在“我的档案”填写姓名、邮箱、手机、学校、学历、专业并保存。资料保存在本地后端的 `profile.job.json`。这是手工结构化录入；上传 PDF 不会自动解析成档案。
2. **开仪表板**：http://127.0.0.1:8787/ → 看清单状态（未投/进行中/已记录），点「打开」进网申页（自动标记进行中）。
3. **设当前目标**：点扩展图标 → 选「当前目标公司」→「设为当前目标」。
4. **匹配简历**（可选）：popup 里粘 JD →「匹配简历」→ 推荐版本会缓存，供上传简历使用。
5. **在网申页**：点扩展图标，先点「在当前网站启用填表助手」。这会只允许扩展在该网站注入工具条；尚未允许的网站不会收到内容脚本。随后：
   - 点右下角 🛠 浮标展开工具条；
   - 「① 填充表单」：扫描页面字段，展示可填写/需确认/需手填清单；核对并取消不想填的字段，再点「填充勾选字段」。写入失败的字段标红；
   - 「② 上传推荐简历」：把推荐简历 PDF 塞进文件上传框；
   - 你本人登录、填开放题、过验证码、**点击提交**。
6. **记录**：扩展检测到"提交成功"页会高亮「③ 记录投递」；点它 → 填岗位标题（公司已预填）→ 确认 → 入库 applications.json，仪表板状态变「已记录」。

## 4. 合规与安全

- 后端仅监听 `127.0.0.1`；CORS 允许扩展来源与本机仪表板，招聘网页本身无法直接读取本地档案。需要给油猴脚本配置招聘站点来源时，用 `AC_ALLOWED_ORIGINS` 显式列出来源。**请勿用 `--host 0.0.0.0` 在本机暴露无令牌服务**。
- 扩展不读取任何账号凭据，不写运行日志；PII 只留在本地 `profile.job.json` / `kits/`。
- 扩展不再默认运行在所有网站。每个招聘网站须由你在 popup 中单独允许；你可随时在浏览器的扩展「网站访问权限」中撤销。
- 绝不自动提交、绝不绕过风控/验证码。
